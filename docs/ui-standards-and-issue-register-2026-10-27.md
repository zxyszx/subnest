# SubNest UI 统一规范与历史问题台账

日期：2026-10-27。范围：网页及响应式手机网页；APK 的原生导航、签名、安装与系统返回需单独验证，网页验证不能代替 APK 验证。生产数据不用于自动化增删改测试。

## 设计判断

当前问题主要是层级和任务流程：页面重复标题、卡片套卡片、首屏统计过多、同类任务打开方式不同。沿用现有品牌与语义配色，先减少阅读和操作负担。参考已提供视频中的内容长度、任务类型与反馈原则，以及 UI/UX Pro Max 的触控、可访问性、渐进披露规则；不因安装了动画插件就增加装饰动画，也不将 Fluent UI 源码包直接替换整个组件体系。

## 全站规则

| 项目 | 规则 |
| --- | --- |
| 页面骨架 | 导航标题 → 当前数据范围/操作 → 摘要 → 搜索筛选 → 列表；同名桌面大标题不再重复展示，保留语义 h1 |
| 间距 | 页面区块 16px；卡片内主要组 12–16px；并列控件 8px；标题与辅助文字 4px；页面边距按设备调整 |
| 边框 | 每个独立内容组一层外边框；组内记录用分隔线；禁止仪表盘外框、分栏框、单条记录框三层叠加 |
| 标题 | 页面 20–24px，卡片 16px，字段 14px，辅助信息 12px；同级同样式 |
| 展开与打开 | 简短辅助内容原位折叠；账号/车友/链接长管理任务桌面右侧面板、手机全屏；删除等短确认用小弹窗；筛选用轻量弹层 |
| 面板 | 标题固定、正文单独滚动、表单操作区固定；关闭后恢复入口焦点和列表位置；打开时不自动选中链接 |
| 复制 | 内容右侧、至少 44×44 点击区域、可见复制图标；备注可整块点击；成功后勾选与提示，失败不显示成功；密码仅主动查看/复制时读取 |
| 按钮 | 主要提交保留品牌色；列表重复管理入口降低强调；危险操作红色且二次确认；异步操作显示等待状态、防止重复提交 |
| 默认信息 | 服务名优先，平台名不同再辅助显示；账号和车位优先；财务详情、密码、链接不默认铺开 |
| 手机 | 不依赖悬停；触控 ≥44px；一处主滚动；底部操作避开安全区；筛选选中状态同时有文字/勾选；平台全部可选 |
| 状态 | 金额由账期计算，输入不可被隐式放大；已收、待收、统计、筛选与卡片徽标采用同一业务口径；保存后刷新相关缓存 |
| 颜色/动效 | 使用现有语义 token，兼顾明暗主题；红色代表异常，不把所有临近日期都当严重错误；保留必要焦点反馈，尊重减少动态效果 |

“统一”指相同任务使用相同规则。登录页、公开验证码页、设置页不必都使用账号管理卡片；长表单也不强行挤进小弹窗。

## 本轮落地顺序

1. 共用页面标题、间距与复制组件，减少页面单独写规则。
2. 仪表盘续费清单、共享卡片与详情信息层级。
3. 订阅详情、车友编辑/续费、账号和链接管理的响应式面板。
4. 本地自动化实际执行：查询筛选 → 打开 → 修改金额/状态 → 保存 → 重开 → 刷新 → 对照列表与统计；复制检查真实成功/失败反馈。
5. 手机与桌面尺寸、暗色、长文本和滚动复核；APK 另行编译安装验证，不能以网页截图宣称 APK 通过。
