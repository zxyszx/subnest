# v0.3.103

本版本统一订阅列表、会员共享和在线 2FA 的平台筛选与搜索体验，并补充共享车位的到期停用提示。

- 三个页面改用同一个平台筛选与搜索工具栏组件，统一搜索框高度、桌面宽度、平台显示数量和“更多”菜单，避免平台图标被截断。
- 保留手机端适合触控的紧凑布局，搜索和筛选区域不会造成页面横向滚动。
- 仪表盘“订阅续费”在相同到期日期下保持订阅列表的原始顺序，不再按平台名称重新排序。
- 家庭共享详情会集中提示已“到期停用”的车位，并使用醒目的行状态；停用车位可直接续费恢复使用。
- 修复平台选择“未绑定”并开启家庭共享后，仪表盘和会员共享接口返回无效数据的问题；未绑定平台现在稳定显示为“未绑定”。
- 仪表盘自动续费项目增加明确文字说明，避免只能依靠图标判断续费方式。
- 设置中的平台搜索补充与订阅编辑一致的搜索入口，减少同一操作在不同页面的差异。
- 完成共享链接、家庭共享、续费列表、订阅排序及中英文文案回归测试。

本版本不新增数据库迁移，升级前仍建议备份数据库。
