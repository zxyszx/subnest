# v0.3.92

本版本继续完善手机端列表体验，并修正 Logo、平台筛选和共享收件箱状态显示。

- 在线 2FA 手机端改为紧凑列表，默认只显示 Logo、序号、平台名称、账号和动态验证码；展开后再显示分享链接与编辑操作，新增 2FA 账号入口同步移到顶部右侧。
- 订阅 Logo 默认按服务名称匹配；更换平台绑定时不再覆盖原有服务 Logo，Logo 搜索也优先使用服务名称，并修复上传 Logo 预览失败时误清空已保存图标的问题。
- 订阅列表的平台筛选只显示当前确实存在订阅的平台，修正未绑定订阅的筛选归类，并在宽屏中利用剩余空间展示更多平台。
- 修正共享收件箱中车位分享链接未计入邮箱共享状态的问题，并压缩手机端筛选区和邮箱列表，使邮箱、共享范围与管理操作更易查看。
- 统一缩小订阅列表、会员共享、日历、统计、设置与共享收件箱等手机页面的区块间距，减少滚动和无效留白。
- 补充 Logo、订阅筛选、在线 2FA 紧凑列表及手机端展开交互的自动化测试。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.91 升级。
