# v0.3.93

本版本重新整理设置页的信息架构，并统一桌面与手机端的设置导航和页面密度。

- 将设置目录归并为“账号与安全、外观与图标、数据与智能、分享与集成、区域与通知”五组，桌面侧栏与手机抽屉使用相同顺序。
- 调整数据配置与预算设置的先后关系，使相关配置连续排列，同时保留所有原有设置入口和业务功能。
- 收窄桌面设置内容区域与侧栏，统一卡片圆角、内边距、标题间距和通知设置布局，减少过多留白。
- 压缩手机端页面标题和区块间距，并修复深色模式下设置目录透出后方内容的问题。
- 新增中英文分组文案，并补充设置导航、延迟加载与响应式布局的自动化验证。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.92 升级。
