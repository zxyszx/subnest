# v0.3.42

## 固定平台与未绑定订阅

- 新增系统设置中的平台管理，可新增、编辑、删除平台，并上传平台图标。
- 支持拖动调整平台顺序，订阅列表会按设置中的顺序展示平台。
- 新增订阅时可以不选择平台，未选择的平台统一归入“未绑定”。
- 编辑订阅时可以重新选择平台，也可以取消现有平台绑定。
- 平台选择支持搜索；平台数量较多时自动收纳到“更多”。
- 平台图标优先使用系统平台配置，兼容已有订阅中的历史图标。

## 数据与兼容性

- 新增平台配置的前后端校验、保存和排序支持。
- “未绑定”使用独立的数据标识，避免被服务名称自动覆盖。
- 保留旧订阅数据兼容逻辑，不要求用户重新录入已有平台。
- 平台名称与服务名称继续独立保存，便于同一平台管理多个服务。

## 验证

- 完成客户端与共享包 TypeScript 类型检查。
- 完成 Docker Server Go 测试。
- 完成订阅表单与平台识别测试。
