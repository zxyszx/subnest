# SubNest v0.3.28

[中文 ->](./v0.3.28-zh.md)

SubNest v0.3.28 fixes amount display in sharing account details.

- Monthly revenue and other summary amounts are no longer truncated with an ellipsis.
- Long amounts can wrap naturally inside summary items and retain a full-value hover title.

This update does not change revenue, profit, or exchange-rate calculations.
