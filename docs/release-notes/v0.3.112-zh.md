# v0.3.112

## 连续滚动与续费卡片优化

- 订阅列表、会员共享和仪表盘续费区恢复连续向下滚动，移除强制一屏分页和页码操作。
- 保留固定侧栏、搜索、快捷筛选及订阅卡片与列表切换，桌面订阅页支持返回顶部。
- 订阅卡片在普通桌面窗口显示三列，宽屏显示四列，减少内容拥挤。
- 仪表盘订阅续费与车友续费使用统一的工作区底色、边界及卡片样式，修正日期、金额和账号信息的对齐。
- 修复手机版平台筛选按固定数量展示导致 Netflix 等平台被裁掉、又未进入“更多”的问题；订阅列表与会员共享均按实际可用宽度收纳。
- 增加桌面滚动、长列表搜索、续费卡片对齐及手机平台选择的浏览器回归检查。
