# v0.3.88

本版本继续完善订阅列表、家庭共享与共享收件箱的关联交互，重点修复邮箱重复显示、验证方式切换丢失选择和窄卡片支付尾号不可见的问题。

- 修复家庭共享邮箱把相同显示名称与邮箱地址重复展示的问题；共享邮箱与在线 2FA 来回切换时保留各自已选记录。
- 调整订阅卡片支付信息布局，支付方式名称与信用卡尾号均完整保留；窄卡片空间不足时自动换行，不再裁掉末四位。
- 合并共享收件箱页面重复的顶部说明，并将“通用分享”改为语义更准确的“管理分享”。
- 邮箱列表直接展示当前分享授权的文件夹名称和可查看时间范围，无需打开弹窗确认。
- 重新设计分享管理弹窗：已分享邮箱先显示当前文件夹、时间范围和链接，按需进入“更改访问范围”；未分享邮箱直接进入配置流程。
- 修改访问范围时提供“保存更改”和旧链接失效提示；重置链接与关闭分享均增加二次确认。
- 新增共享收件箱、家庭共享模式切换和支付信息布局的组件回归测试。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.87 升级。
