# v0.3.131

## 妙妙屋费用信息正式首页

- 正式首页使用妙妙屋紫色棋盘、蕾丝卡片、顶部导航图标及名称图标，将流量信息调整为费用信息。
- 提供仪表盘、车友、合租、服务器四个分页，接入现有订阅、合租、车位、应收及汇率数据。
- 仪表盘展示月均支出、合租收入、车位占用、待收款、未来 30 天续费费用、月均收支、费用分布，并保留需要处理和服务状态。
- 服务器页提供收款进度散点图、未来 60 天下次续费时间轴、已知月度续费汇总，以及搜索、到期和暂停筛选、排序与服务卡片。
- 费用页只读展示，管理操作通过顶部入口进入现有功能；保留居中任务窗口及单层可见弹窗交互。
- 月均折算、下次预计续费与实际付款分别说明；历史在车人数缺少账本时明确提示，不生成模拟记录。车友分页目前按真实车位记录展示。
- 补充桌面和手机尺寸的正式页面验证，检查分页、筛选、图标加载、页面宽度与管理导航。
