# v0.3.82

## 订阅卡片与共享链接

- 优化卡片平台名称、账号和价格的对齐；账号保持单行，超长省略并可查看完整内容。
- 恢复卡片的试用、活跃、已过期等状态标签。
- 家庭共享未开启或共享账号暂停时，会员共享的查看链接入口不可用。
- 暂时隐藏车位链接入口并停止自动生成新车位 2FA 链接，仅展示通用链接，缩短弹窗。
- 邮箱通用链接统一在共享收件箱选择允许查看的文件夹后配置；会员共享仅查看和复制。
- 文件夹加载失败或未选择文件夹时禁止创建链接，防止使用上一个邮箱的残留选择。
- 隔离邮箱和在线 2FA 配置，邮箱通用链接同步不再覆盖在线 2FA 订阅。

## 升级与安全

- 通用 2FA 链接不再固定 30 天到期；关闭家庭共享、禁用或变更密钥、重置或撤销仍会使链接失效。
- 仅将尚未到期且未撤销的旧通用 2FA 链接升级为长期有效，不恢复已经失效的授权。
- 历史车位链接数据保留，继续受原有到期和访问校验限制。
- Cloudflare 使用新增的 `0049_family_totp_default_lifetime.sql`；Docker 启动时自动升级。
- 更新前备份数据库。回滚不自动恢复通用链接之前的固定到期时间，需要时应手动撤销链接；不要删除历史共享表。

## 验证

- 完整前端、Worker、Go 单元测试及类型检查通过。
- 桌面、手机、深浅主题实测卡片账号和通用 2FA 链接弹窗，测试使用隔离数据。
