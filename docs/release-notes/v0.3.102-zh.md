# v0.3.102

本版本重构共享链接管理，并修复公共在线 2FA 与共享邮箱公开页面的信息显示问题。

- 共享邮箱和在线 2FA 统一使用新的车位链接管理界面：公共链接、折叠设置、车位搜索与排序、到期时间和剩余天数集中展示。
- 电脑端使用清晰的车位表格，移动端改为独立卡片布局；主要操作保留“复制上车信息”，复制链接、打开、重置与撤销收纳为次级操作。
- 修复手机弹窗无法上下滑动的问题，使用动态视口高度、独立滚动容器和触摸惯性滚动，并避免横向溢出。
- 公共在线 2FA 链接现在也会显示对应共享账号和密码；车位链接继续显示正确车位号、成员与到期时间。
- 修复订阅平台图标可能被空值覆盖的问题，在线 2FA 页面会正确回退到已有服务图标。
- 共享邮箱公开页面现在显示真实授权文件夹名称，例如 Netflix，不再直接显示内部文件夹 ID。
- 关闭公共分享、重置链接和撤销链接均保留确认步骤；升级不会主动修改、停用或重置任何现有分享链接。
- 完成 Worker、Docker、Web 单元测试，以及 59 项电脑端和移动端浏览器回归测试。

本版本不新增数据库迁移，升级前仍建议备份数据库。
