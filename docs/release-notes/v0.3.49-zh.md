# v0.3.49

## 原生在线 2FA 管理

- 顶部导航在“合租”右侧增加“在线 2FA”，无需再跳转到外部管理网站。
- 新增 2FA 账号列表、固定平台筛选、搜索、账号复制、验证码复制和编辑入口。
- 编辑账号支持平台名称、服务名称、序号、登录账号、Logo、Base32 密钥或 `otpauth://` 链接。
- 支持暂停验证码生成、暂停分享、重置分享链接和删除账号；重置与删除均有二次确认。
- 分享页面会自动刷新六位验证码与倒计时，并适配电脑和手机屏幕。

## 数据与安全

- Docker 与 Cloudflare 只共用 API 和字段校验规则，不共用数据库或实际账号数据。
- Docker 数据保存在本机 SQLite/PocketBase；Cloudflare 数据保存在当前部署的 D1，两边互不读取、互不同步。
- 每种部署都使用自己的主密钥派生独立的在线 2FA AES-GCM 密钥；原始 2FA 密钥不会返回前端，也不会写入日志。
- 分享链接使用高强度随机令牌，数据库只用哈希查找；重置后旧链接立即失效，暂停后公开页面不可访问。
- 所有管理接口都校验登录用户的数据所有权，避免跨用户读取或修改账号。

## 升级说明

- 不新增环境变量。Docker 启动时自动创建本地集合，Cloudflare 发布流程自动应用 D1 迁移。
- 现有订阅、合租、共享邮箱和车位数据保持不变。
- Docker 用户可继续使用原有系统更新方式升级。
