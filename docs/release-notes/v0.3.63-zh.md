# SubNest v0.3.63

## 发布修订

- 完成 v0.3.62 仪表盘、日历、订阅续费、会员共享与订阅列表改版的正式发布。
- 补齐订阅集合测试夹具中的标签字段，确保 Docker、Cloudflare Worker 与网页端的数据契约一致。
- 修复 Cloudflare 完整检查链的严格类型错误，发布前同时验证 Worker 测试与前端全量类型检查。

## 主要更新

- 日历按日期左右展示续费支出与合租收入，支持年月选择、日期明细及随月份变化的支出、收入和净利润汇总。
- 订阅列表精简筛选栏，支持序号搜索与排序，并在卡片中展示标签和清晰的续费操作。
- 续费操作增加二次确认、支付方式和卡号尾号；订阅续费与车友续费恢复可读尺寸。
- 会员共享强化车位分隔、密码与链接状态提示、联系方式图标和收费周期选择。
