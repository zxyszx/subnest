# v0.3.73

## 订阅卡片与共享弹窗收尾优化

- 订阅卡片移除日均支出，收拢信息层级，保留平台、差异化服务名称、价格、到期提醒、开始日期、支付方式和续费操作。
- 开启家庭共享且填写登录账号后，在订阅卡片的平台信息下显示共享账号；关闭共享时不显示。
- 私有订阅列表新增最小化家庭账号摘要，Docker 与 Cloudflare 运行端保持一致，且不会返回密码或验证码链接。
- 减弱临近到期卡片的闪烁强度并放慢动画；4 至 7 天使用黄色提醒，0 至 3 天使用红色提醒，过期保持静态红色，并支持减少动态效果设置。
- 共享账号与车位管理弹窗改为按内容自适应高度，桌面车位表格局部滚动，减少大面积空白；移动端继续使用单一纵向滚动区域。
- 保留换位的两阶段流程：先按序号、账号或邮箱搜索目标账号，再选择该账号的空闲车位。
