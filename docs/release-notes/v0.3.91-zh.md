# v0.3.91

本版本修复 v0.3.90 发布流程被端到端测试拦截的问题，恢复应用内新版本检测和下载安装能力，并完整包含 v0.3.90 的功能更新。

- 修正手机端订阅卡片展开操作的自动化测试，使日历订阅管理在紧凑卡片模式下稳定打开。
- 更新长账号在手机端截断显示的布局校验，同时继续检查卡片没有横向溢出，并保留完整账号提示。
- 修正共享收件箱测试在手机视图后未恢复桌面视图的问题，确保“查看链接”禁用状态按实际界面验证。
- 保留 v0.3.90 的同账号车位互换、同平台不同账号换位、手机紧凑列表、可选登录密码和中文错误提示等全部改进。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.89 或 v0.3.90 升级。
