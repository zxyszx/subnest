# v0.3.99

本版本重构车位分享管理与公开分享页面，让车主可以直接复制完整上车信息，并让车友在一个链接内查看所需内容。

- 会员共享列表中的“查看链接”调整为“分享管理”，链接复制、页面预览和完整上车信息复制集中在同一处。
- 车位专属共享邮箱链接显示平台图标、车位序号、车友、到期日期、登录账号、密码及授权文件夹；邮箱正文仍可在同一页面查看。
- 车位专属在线 2FA 链接显示平台图标、车位序号、车友、到期日期、登录账号、密码及动态验证码，不显示共享邮箱文件夹。
- 默认链接与非车位链接继续隐藏账号密码，避免扩大敏感信息的可见范围。
- 重置和停用移入二级操作菜单，降低误操作风险；既有链接地址、启用状态和有效期不会因升级而改变。
- 优化桌面端弹窗密度与移动端布局、滚动和详情返回交互，小屏页面不再横向溢出。
- 更新发布冒烟测试与在线 2FA 端到端测试，使发布门槛覆盖新的按钮名称、二级操作菜单和车位到期显示。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.97 升级。
