# v0.3.101

本版本为家庭共享增加可选的自定义附加信息，并完成电脑端、移动端及 PWA 页面回归检查。

- 家庭共享新增“附加信息”，可自定义名称和内容，例如“最近通知”或“R21 限制 PIN”；内容会直接显示并支持复制，不按密码隐藏。
- 登录密码改为可选，Netflix 等不需要密码的共享订阅可以留空创建和编辑。
- 附加信息仅显示在对应车位的共享邮箱或在线 2FA 公开页面；未设置、暂不设置验证方式或普通公共链接不会显示空项目。
- 复制上车信息时会包含已配置的附加信息，便于一次发送完整资料。
- 修复编辑订阅时附加信息在 React 严格模式下可能一直加载、异步默认值可能覆盖表单草稿的问题。
- 更新电脑端和移动端端到端测试，覆盖无密码保存、附加信息持久化、公开页面展示、移动端无横向滚动和 PWA 独立模式。
- 修正本地与 Cloudflare 部署巡检的测试边界，并同步设置页重构后的巡检路径。

本版本不新增数据库迁移。附加信息沿用现有加密凭据存储，升级前仍建议备份数据库。
