# SubNest v0.3.29

[中文 ->](./v0.3.29-zh.md)

SubNest v0.3.29 improves mouse interaction feedback on desktop.

- Buttons, links, selects, menu items, labels, and clickable cards now consistently use a pointer cursor.
- Disabled controls use a not-allowed cursor to make their state clear.
- Dropdown menus and searchable selects retain their hover highlights with consistent cursor feedback.

This update does not change touch behavior on mobile or any business logic.
