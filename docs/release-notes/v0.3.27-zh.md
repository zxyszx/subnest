# SubNest v0.3.27

[English ->](./v0.3.27-en.md)

SubNest v0.3.27 是首个由 `zxyszx/subnest` 独立发布的版本。

- 新增合租账号、车位、车友续费、应收款、月收入与多币种利润管理。
- 订阅与合租共用平台、账号、成本、支付方式、卡尾号和续费日期数据。
- 仪表盘、日历和统计增加合租收入、利润与车友到期信息。
- 系统更新只检查 `zxyszx/subnest` 的 GitHub Release，不再自动同步或安装 Renewlet 版本。
- Docker 镜像改由 `ghcr.io/zxyszx/subnest` 独立发布。

SubNest 基于 Renewlet 开发，并继续保留原项目作者与贡献者的 MIT 许可和版权声明。
