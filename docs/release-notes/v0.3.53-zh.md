# SubNest v0.3.53

本版本修复合租页面首次打开订阅编辑弹窗时，分类与支付方式未正确回显的问题。

## 仪表盘改进

- 概览区由六项压缩为四项核心指标，降低首屏信息噪音。
- “即将续费/到期”移至顶部工具按钮，以数量徽标提示，点击后再显示详细列表。
- 删除右侧重复的续费列表，支出分布成为更紧凑的独立分析区。
- 近期订阅首屏展示 6 项，完整内容继续通过订阅列表查看。

## 修复

- 合租页点击平台 Logo 后，完整订阅详情到达时重新建立内部表单会话。
- 分类和支付方式现在会在首次打开编辑弹窗时直接显示，无需关闭后重新进入。
- 加载期间继续保留稳定的弹窗外壳和表单骨架，避免空字段短暂可编辑。
- 同一订阅在弹窗打开后的缓存刷新不会覆盖用户尚未保存的编辑内容。

## 验证

- 增加异步详情加载后分类与支付方式回显的回归断言。
- 增加仪表盘顶部续费入口按需显示、四项概览与近期订阅数量的回归测试。
- 更正 v0.3.52 验收清单中对该问题的错误完成标记。
