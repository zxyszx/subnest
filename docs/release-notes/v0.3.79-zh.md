# v0.3.79

## 车位独立限时共享链接

- 每个车位可生成独立、有期限的只读邮箱链接，支持单独复制、重置和撤销，不影响其他车位。
- 链接限定邮件文件夹、可见时间范围和有效期；访问时检查车位、邮箱、订阅与共享状态。
- 更换车友、换位、停用车位或更换共享邮箱时撤销相关链接，避免旧链接继续访问。
- 家庭共享开关只控制当前订阅的车位链接，不关闭邮箱原有的普通分享。
- 收紧共享配置排版，增加可滚动的车位链接管理弹窗，适配桌面和手机。
- 邮箱列表区分普通分享与车位分享，显示车位链接数量。

## 升级注意事项

- Cloudflare Worker 部署前需应用新增 D1 迁移 `0047_shared_inbox_seat_links.sql`；Docker/PocketBase 启动时自动补齐对应字段与索引。
- 原有普通邮箱分享链接不会自动撤销。迁移到车位独立链接后，如需严格隔离访问，请主动撤销此前发出的普通链接。
- 回滚前应在新版本中撤销车位链接，避免旧版本缺少车位权限检查。详细说明见 `docs/seat-inbox-links.md`。
- 自动分配、临时邮箱分类、批量管理与分配日志不在本次发布范围内。邮箱上游服务尚未完成真实环境联调。
