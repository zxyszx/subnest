# SubNest v0.3.124

重做仪表盘、订阅列表和会员共享的核心工作区，减少手机上的重复展开与滚动。

- 仪表盘优先展示今日续费、逾期待办，订阅与车友续费使用独立面板。
- 订阅默认卡片展示，保留桌面列表切换；手机收纳状态显示服务名称、到期日、支付方式与续费入口，点击直接打开详情。
- 会员共享统一为响应式账号卡片，显示车位、最近到期和管理入口；管理账号默认展示车位，账号资料与经营概览按标签访问。
- 搜索保持可见，筛选选中状态更清晰；桌面统计金额不再被图标遮挡。
- 未配置分享时给出说明，并保留订阅过期提示。

已验证手机和桌面浏览器的仪表盘、订阅续费、会员管理与验证码链接；本地真实后端验证 15 元、已收状态保存及重新读取，确认不会错误进入待收款筛选。Android 配套发布 0.1.0-preview.4，增加总览、车位编辑与续费、链接管理，仍为预览版。

Docker 镜像：`ghcr.io/zxyszx/subnest:0.3.124`。更新时保留现有数据挂载。本次不涉及数据库迁移。
