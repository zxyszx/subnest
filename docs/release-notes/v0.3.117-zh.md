# v0.3.117

## 会员共享账单回显与间距修复

- 本期收费、收款状态按车位保存的开始日和到期日匹配账单，避免读取到期限更长的其他历史账单。
- 修复同时存在多条账单时，保存 15 元、已收后仍回显旧的 45 元、待收的问题。Docker 和 Cloudflare 运行时同步修复。
- 会员共享页统计卡片间隔、顶部留白、统计区到平台栏的距离统一为 16px；较窄桌面采用三列，宽屏采用六列。
- 历史账单保留，不自动改写历史金额或收款状态；下一轮续费仍默认待收。

验证：先用真实本地后端复现错误，再验证修复。手机操作、保存后重开、桌面 1280/1536/1920px 间距检查通过；Go 共享相关测试、Cloudflare 11 项相关测试、类型检查、Lint、前端生产构建通过。
