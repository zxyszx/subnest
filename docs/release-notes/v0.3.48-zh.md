# v0.3.48

## 合租账号管理弹窗排版优化

- 管理账号弹窗调整为收益概览、账号资料、车位列表三大区域。
- 桌面端压缩收益和账号资料的纵向占用，账号、密码、验证码链接和一键复制操作更紧凑。
- 车位表改为占用弹窗剩余空间，电脑屏幕高度不足时只滚动车位区域，避免车位被弹窗底部遮挡。
- 车位表头在滚动时保持可见，方便查看多个车位的状态和快捷操作。
- 移动端继续使用纵向布局，保留完整的账号复制、密码查看和车位管理操作。
- 验证码链接改为通用 HTTPS 地址，可直接填写 CloudOTP 等外部 2FA 链接；邮箱共享链接不再锁定输入框或覆盖手动地址。
- 顶部导航增加“在线 2FA”入口，直接打开 CloudOTP 管理页。

## 升级说明

- 本版本不包含数据库迁移或新增环境变量。
- Docker 用户可以从系统更新页面升级，原有订阅、共享邮箱和车位数据保持不变。
