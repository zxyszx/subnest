# v0.3.115

## 手机列表操作优化

- 订阅列表、会员共享共用手机工具栏，完整平台下拉常驻，便于选择 Netflix 等平台。
- 搜索框全宽显示；输入搜索时收起次要筛选，让查询结果更容易看到。
- 有空位、已满、到期、逾期等快捷筛选增加勾选和明显选中底色，扩大触控区域。
- 手机共享页折叠次要统计，卡片直接提供管理账号入口，保留纵向滚动。
- 更新表单分组后的回归测试；手机端 11 项浏览器操作测试通过。
