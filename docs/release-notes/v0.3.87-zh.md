# v0.3.87

本版本修复订阅编辑中切换“在线 2FA 验证”后弹窗内容滚动为空白的问题，并补齐订阅、会员共享、在线 2FA 与共享收件箱之间的联动回归检查。

- 修正家庭共享验证方式控件的焦点与滚动行为；切换共享邮箱或在线 2FA 时，配置区、家庭共享开关和底部操作始终保持在正确视口内。
- 保留验证方式控件的原生单选语义、键盘操作和清晰焦点状态，避免为修复滚动问题牺牲可访问性。
- 扩展在线 2FA 联动测试，覆盖账号列表、分享链接、编辑弹窗、重置链接确认和删除确认。
- 校正会员共享 2FA 链接的回归标准：默认链接与所有车位链接统一长期有效，重置链接仍需二次确认。
- 串行验证订阅列表、会员共享、在线 2FA 和共享收件箱，覆盖桌面端、移动端、文件夹选择约束及车位链接展示。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.86 升级。
