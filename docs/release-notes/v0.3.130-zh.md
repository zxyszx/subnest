# v0.3.130

## 保留简洁界面，统一任务窗口交互

- 保留原有首页与管理页面，移除上一版妙妙屋独立预览入口与页面。
- 订阅详情、编辑表单、车位管理和链接管理等任务窗口改为居中显示，取消左右侧展开样式。
- 同一流程只显示当前任务窗口和一层遮罩；进入编辑、续费、详情或删除确认时暂时隐藏上一窗口，返回后恢复草稿、滚动位置与焦点。
- 手机端的类别、标签、日历导出、通知详情和备份列表统一采用居中窗口，取消拖拽抽屉行为。
- 表单窗口内的选择器、日期与更多菜单直接就近展开，不再新增手机底部浮层；展开区域受所在窗口可用空间约束。
- 保留删除、撤销链接等敏感操作的确认步骤，并检查取消、关闭和切换页面后的浮层清理。
