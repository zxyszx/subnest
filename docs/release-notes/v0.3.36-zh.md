# v0.3.36

## NewSzxcn 共享收件箱

- 新增独立的“共享收件箱”管理页面，管理员可配置 API 地址与只读令牌，并在刷新页面后自动恢复邮箱和分享状态。
- 邮箱按 A-Z 排序，支持账号片段搜索以及全部、已分享、未分享筛选；每个邮箱集中提供开启、管理、复制、预览、重置和关闭分享操作。
- 分享范围支持 30 分钟、1 小时、6 小时、1 天和 7 天，并可选择具体邮件文件夹。
- 新增可撤销的 SubNest 短链接；浏览器不会收到 NewSzxcn API 令牌、原始分享令牌或邮箱 API 地址。
- Docker 与 Cloudflare Worker 运行模式均支持邮箱列表、文件夹、邮件列表、邮件正文和附件的只读代理。

## 家庭共享与访客页面

- 家庭共享登录账号支持搜索 NewSzxcn 邮箱；仅在精确匹配后台邮箱时显示托管分享控制，普通邮箱继续使用手动收件链接。
- 匹配后台邮箱后可直接开启默认 30 分钟的只读分享，并在账号详情中复制或管理短链接。
- 访客收件箱改为桌面端列表/正文分栏、移动端列表/正文切换，补充附件入口和清晰的失效、撤销、过期提示。
- 邮件 HTML 在隔离的沙箱中显示，禁止脚本、表单、远程资源和来源泄露。

## 安全与一致性

- NewSzxcn API 地址固定为 `https://mail.newszxcn.com`，拒绝端口、用户信息、查询参数和片段，降低 SSRF 风险。
- 所有共享读取均要求当前有效授权；重置或关闭分享后旧短链接立即失效。
- 共享时长在前端、共享模型、Docker 后端和 Worker 中使用同一组允许值。
- 修正共享收件箱接口响应解析和 Docker 路由参数格式，并移除已经实现的运行时差异白名单。
