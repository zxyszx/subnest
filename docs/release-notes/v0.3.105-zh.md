# v0.3.105

本版本优化订阅列表与会员共享的桌面筛选工具栏，让搜索和筛选操作更加紧凑。

- 两个页面复用同一套平台、搜索和筛选工具栏。
- 搜索默认收起为图标，点击后自动聚焦并平滑展开；有搜索内容时保持展开，清空并失焦后收起。
- 支持系统减少动态效果设置。
- 桌面平台按钮及筛选框采用更紧凑的尺寸，手机原有点击区域保持不变。
- 调整中等桌面宽度下的平台显示数量，缓解平台入口被裁切的问题。
- 补充搜索展开、溢出平台菜单及选中平台展示的回归测试。

已知问题：平台折叠数量仍按屏幕断点计算；较窄窗口、较长平台名称或搜索展开时，仍可能出现平台入口裁切。后续需要改为根据容器实际宽度计算。

本版本未调整日历、收入及利润计算，不新增数据库迁移。
