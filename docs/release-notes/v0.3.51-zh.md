# SubNest v0.3.51

本版本完善在线 2FA、合租车位和订阅到期管理，并统一了主要页面的操作布局。

## 新功能与改进

- 新增 SubNest 原生在线 2FA 管理、动态验证码和可重置的公开分享链接。
- 在线 2FA 支持复用已有平台与 Logo，同平台账号编号重复时即时提示。
- 优化在线 2FA 列表、复制交互、搜索区域和公开分享页的响应式布局。
- 合租车位支持月付、双月、季付、半年付、年付及自定义月数的收费换算。
- 新车位默认月付，本期收费默认留空；车位编号与联系方式平台更易识别。
- 联系方式新增 NS 论坛和闲鱼，并同步支持 Docker 与 Cloudflare 部署。
- 仪表盘的即将续费/到期统计支持点击查看详情，并纳入已过期订阅。
- 已过期订阅使用清晰的危险色渐变状态，同时保持文字对比度。
- 公开 2FA 与共享收件箱页面自动跟随设备日间或夜间模式。
- 订阅季付、半年付、年付和自定义周期支持自动计算月均费用与到期日期。

## 修复

- 修复合租页面首次打开订阅编辑弹窗时分类、状态和支付方式未回显的问题。
- 修复共享收件箱邮件正文中的安全链接无法正常点击打开的问题。
- 修复小数金额输入受步进限制的问题。
- 修复导航栏在不同页面同时显示无关新增操作的问题。
