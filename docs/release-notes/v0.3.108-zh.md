# v0.3.108

## 桌面工作台

- 参考邮箱工作台交互，将首页、订阅列表和会员共享改为固定导航、固定工具栏和底部分页；每页条数随列表区域高度调整。
- 首页精简为月均收入、月均支出、月均净收益、可招募车位及续费待办，移除预测图、平台经营概览和重复排行。
- 月均净收益统一为月均收入减月均订阅支出。这是现有合同和订阅按月折算的经营指标，不是实际到账流水。
- 订阅列表默认使用紧凑表格，保留卡片切换、详情、编辑、续费、复制、置顶、公开设置和删除确认。
- 订阅列表与会员共享共用搜索栏、快捷筛选和分页组件；先全库筛选，再分页，数字搜索精确匹配账号序号。
- 按 `/` 聚焦搜索；按 `Alt+数字` 切换对应快捷筛选。输入框或弹窗操作中不抢占快捷键。
- 移动端保留原有底部导航与触屏列表交互。

## 修复

- 今日续费仅显示今天到期的订阅，逾期订阅仅显示已逾期记录，弹窗标题与筛选一致。
- 续费列表取消 Logo 的额外灰黑底板，修复“今天”文字、续费按钮与滚动条间距。
- 筛选变化时回到第一页，删除记录后自动修正超出的页码。

本次不修改数据库结构、车位链接权限和手动收款续费规则，也不迁移现有账户数据。
