# SubNest v0.3.61

## 仪表盘日历

- 在续费日历底部恢复本月续费支出、合租收入和净利润汇总，切换年月时同步按所选月份重新计算。
- 统一日历金额为紧凑格式，保持支出和收入左右对齐，避免金额较长时挤压日期格。
- 净利润按当月合租收入减去订阅续费支出计算，并根据盈亏状态区分颜色。

## 续费列表

- 压缩桌面端订阅续费和车友续费卡片的内边距、行高、图标及金额字号，减少无效空白。
- 保留弹窗中的默认信息密度，仅对仪表盘预览列表使用紧凑布局。
- 统一统计卡片使用紧凑金额格式，避免笔记本宽度下币种和金额被截断。

## 会员共享

- 将车位收费周期精简为月付、季付、半年付、年付和自定义五个入口，移除“2 个月”预设。
- 自定义月数改为按需展开，避免周期按钮和输入框挤在同一行。
- 已保存的非预设周期继续作为自定义月数加载和编辑，不影响现有车位数据。
