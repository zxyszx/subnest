# v0.3.41

## 家庭共享与共享收件箱

- 编辑订阅中的后台邮箱改为直接选择可查看文件夹，不再自动选择收件箱。
- 未选择文件夹时不能开启共享，也不能保存未完成的家庭共享设置。
- 共享收件箱创建、关闭和重置时同步订阅中的收件链接，避免合租页面继续显示旧链接。
- 对已有共享链接增加同步修复，限制在当前用户和匹配邮箱范围内，避免误改其他订阅。
- 优化手机端家庭共享布局，减少按钮拥挤并保留清晰的加载状态。

## 修复与验证

- 增加文件夹选择和共享链接同步回归测试。
- 完成前端类型检查、前端组件测试、PocketBase 后端测试、Cloudflare Worker 类型检查和生产构建检查。
