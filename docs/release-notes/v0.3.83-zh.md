# v0.3.83

本版本包含 v0.3.82 的全部卡片与共享链接改进，并修复旧发布测试仍依赖车位链接入口的问题。v0.3.82 未完成发布，请更新至本版本。

- 订阅卡片账号单行显示，超长省略并可查看完整内容；恢复试用等状态标签。
- 家庭共享未开启时，会员共享的查看链接入口置灰。
- 暂时隐藏车位链接入口，仅展示紧凑的通用链接弹窗。
- 邮箱通用链接必须在共享收件箱选择允许查看的文件夹后生成，会员共享只查看、复制。
- 修复文件夹加载失败或切换邮箱时的残留选择；已过期通用邮箱链接仍可撤销、重置。
- 邮箱链接同步不再覆盖在线 2FA 配置。
- 通用 2FA 链接长期有效，但关闭家庭共享、变更或禁用密钥、重置或撤销仍会使其失效。
- 仅升级未过期、未撤销的旧通用 2FA 链接，历史车位链接保留原有校验与到期限制。

升级前备份数据库。Cloudflare 使用 `0049_family_totp_default_lifetime.sql`，Docker 启动自动升级。回滚不会恢复之前的固定到期时间，需要时应撤销链接，不应删除历史共享表。

本地完整前后端单元测试、类型检查、网页构建、代码检查及 7 项发布冒烟测试通过。依赖安全审计仍有仓库已有的 Hono、Undici 等告警，本版本不宣称消除了所有依赖风险。
