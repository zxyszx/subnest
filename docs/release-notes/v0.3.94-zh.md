# v0.3.94

本版本继续简化设置页面，将原先连续堆叠的设置项改为更清晰的分组目录和单模块工作区，并统一桌面与手机端体验。

- 设置页改为一次只显示当前模块，减少长页面滚动和功能之间的视觉干扰。
- 桌面端保留分组侧栏，手机端使用分组抽屉，并在标题区显示当前栏目和所属分组。
- 支持通过 URL 锚点直接打开指定设置模块，刷新后仍保持当前位置。
- 切换模块时保留未保存的表单状态，延迟加载完成后不会跳回默认栏目。
- 统一账户、外观、显示、数据配置、预算、汇率、时区和通知模块的标题、图标、说明与操作布局。
- 将“数据与智能”重新排序为数据配置、预算、汇率、AI 识别和云端备份，并补充桌面与手机端自动化测试。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.93 升级。
