# v0.3.86

本版本继续优化订阅列表与家庭共享的操作逻辑，重点修正卡片信息排版、家庭共享开关和已占用车位的关闭约束。

- 重新整理订阅卡片头部：平台、账号与状态集中展示，完整账号支持自然换行，金额与币种独立占据稳定区域，避免长账号和不同货币相互挤压。
- 恢复订阅编辑中的家庭共享总开关；关闭后仅隐藏共享配置并保留原有内容，再次开启时无需重新填写。
- 家庭共享验证方式收敛为“共享邮箱”和“在线 2FA 验证”，不再用第三个选项代替总开关。
- 修复切换家庭共享或在线 2FA 时编辑弹窗内容被滚动到空白区域的问题，标题、配置区和底部操作始终保持可见。
- 订阅详情新增会员共享非空闲车位数量；存在已占用或暂停车位时，家庭共享开关保持开启并禁用，同时明确提示需先将全部车位设为空闲。
- Docker 与 Cloudflare Worker 同步加入服务端关闭校验，直接调用接口也无法绕过车位状态限制。
- 补充组件、完整编辑弹窗、Worker、Docker 与 Playwright 回归测试，覆盖卡片排版、开关切换、占用数读取和关闭冲突。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.85 升级。
