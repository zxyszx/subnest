# SubNest v0.3.125

统一订阅、会员共享与仪表盘的页面层级和操作方式，减少重复标题、边框以及手机上的展开和滚动。

- 账号、车友、订阅和验证码链接的长管理任务统一使用桌面侧边面板、手机全屏面板；表单标题与保存栏固定，正文单独滚动。
- 会员共享精简统计与重复入口，突出车位和空闲数量，统一卡片对齐；财务与账号凭据按需查看。
- 仪表盘续费分区减少多层边框，订阅续费和车友续费均显示所属登录账号，优先显示服务名称。
- 网站、备注与账号资料使用一致的复制反馈：成功显示勾选，失败明确提示；密码仅在主动操作时读取。
- 复制订阅显示已用账号编号与可用编号建议，支持一键填入，减少编号冲突。
- 车友续费精简无关字段，保留金额、周期、日期和收款状态；优化窄屏按钮和底部操作区。
- 订阅列表、会员共享、日历、统计及共享收件箱统一标题与间距规则。

本地已通过 14 个联合浏览器流程、163 项相关单元测试（另有 2 项跳过），并验证 15 元金额、已收状态保存重开以及待收筛选。另通过 8 项发布流程测试（包含登录、备份恢复和修改密码后重新登录）。远程构建结果以本版本 Actions 为准。

Docker 镜像：`ghcr.io/zxyszx/subnest:0.3.125`。更新时保留现有数据挂载。本次不涉及数据库迁移。

本版本为网页更新，未发布新的 Android APK。
