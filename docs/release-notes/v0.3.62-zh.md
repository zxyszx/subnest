# SubNest v0.3.62

## 仪表盘与日历

- 修复续费支出和合租收入在跨月日期格中错位、串列的问题，支出固定显示在左侧，收入固定显示在右侧。
- 日历支持点击年月直接选择年份和月份，并可点击日期查看当天的订阅续费与车友收费明细。
- 月度续费支出、合租收入和净利润会随所选月份重新计算，周期项目也能在历史月份正确投影。
- 调整仪表盘统计卡片、日历和续费区域的间距与信息密度，恢复续费列表的可读字号和行高。

## 订阅与续费

- 精简订阅列表工具栏，保留平台、搜索和排序，数字搜索默认匹配订阅序号。
- 新增序号正序和倒序，保留到期最近与到期最远排序。
- 订阅卡片显示已保存标签，并按平台名称与服务名称是否相同决定单行或主副标题展示。
- 续费入口改为明确按钮，续费前增加二次确认，并展示支付方式和卡号尾号。
- 订阅续费与车友续费列表统一尺寸，减少内容较少一侧产生的大块空白。

## 会员共享与 2FA

- 强化车位之间的分隔，以及密码和验证链接已填写、未填写两种状态的视觉提示。
- 联系方式按微信、Telegram、N 论坛和闲鱼使用不同颜色与图形显示。
- 收费周期统一为月付、季付、半年付、年付和自定义，自定义周期按需展开。
- 保持在线 2FA 的紧凑平台筛选、账号、验证码和快捷操作布局。

## 数据一致性

- Docker 与 Cloudflare Worker 的订阅集合接口均返回标签，确保列表卡片能够显示编辑时保存的标签。
- 补充日历周期投影、续费确认和 Worker 集合查询回归测试。
