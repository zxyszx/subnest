## 手机卡片与共享账号信息收纳

- 订阅卡片及列表优先显示具体服务名称；平台不同于服务时在下方显示平台，手机收起状态也能区分服务器。
- 手机订阅卡片的续费操作行显示支付方式和卡尾号，缩小分隔留白，保留按钮触控空间。
- 共享账号详情默认先显示车位和车友操作；经营金额、续费和支付信息整理为可展开卡片。
- 登录账号、密码和验证码链接单独收起，展开后仍可查看和复制；不修改金额、账单或收款状态。

验证：66 项相关组件测试通过；本地真实后端手机浏览器操作验证通过，包括折叠展开、复制入口、平台筛选、订阅续费及车友 15 元已收状态保存回读；前端类型、Lint、构建检查通过。
