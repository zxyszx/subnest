# v0.3.37

## 共享收件箱

- 将共享收件箱管理整合到“设置”，并保留旧地址兼容跳转，减少顶部导航占用。
- 统一设置项名称与分组，优化 API 连接状态、邮箱列表和管理弹窗的层级与文案。
- 将系统文件夹名称本地化；可查看范围改用一致的应用内选择器，修复系统下拉菜单颜色异常。
- 修正家庭共享中的名称与管理入口，托管邮箱操作现在携带完整的登录和防跨站请求凭据。
- 普通邮箱可直接清空手动收件链接；托管邮箱若残留旧的原始分享地址，会自动移除并改用 SubNest 短链接。
- 管理弹窗打开时不再自动全选短链接，复制、预览和重置操作仍随时可用。

## 邮件刷新与订阅复制

- 共享收件箱每 15 秒静默更新，并在页面重新可见时立即刷新，新邮件无需手动点击刷新。
- 修复复制订阅后修改序列号再保存没有反馈的问题：保存会使用编辑后的值、等待服务端完成，并在失败时保留弹窗显示原因。
- 保存期间禁用重复提交，避免双击或连续回车创建重复订阅。

## 安全

- 继续保持共享收件箱只读代理边界，浏览器不接触 NewSzxcn API 密钥、上游 API 地址或原始分享令牌。
- 共享邮件正文继续在隔离沙箱中显示，阻止脚本、表单、远程资源和来源信息泄露。
