# SubNest v0.3.54

本版本修复订阅列表默认排序遗漏已过期项目的问题，并恢复仪表盘常驻的续费提醒区域。

## 订阅列表

- 所有平台及单个平台筛选默认按“到期最近”排序。
- 已过期订阅按真实到期日进入待处理序列，并排在未来到期项目之前，方便及时续费。
- 已暂停和已取消订阅继续排在待处理项目之后；手动置顶保持最高优先级。

## 仪表盘

- 删除顶部“即将续费/到期”时钟按钮及数量角标。
- 在“支出分布”下方恢复常驻的“即将续费/到期”卡片，并显示已过期项目。
- 同步恢复对应的加载骨架布局。

## 验证

- 前端单元测试与性能测试通过。
- 前端类型检查、代码检查和生产构建通过。
- 移动端即将续费金额布局端到端测试通过。
