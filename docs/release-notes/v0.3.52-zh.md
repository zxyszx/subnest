# SubNest v0.3.52

本版本继续优化在线 2FA、公开验证码页面与合租订阅编辑体验。

## 新功能与改进

- 在线 2FA 平台名称改为项目内统一样式的可输入下拉选择器，并自动复用已有平台 Logo。
- 新增 2FA 账号时账号编号默认留空，同平台重复编号会在字段下方提示“已经添加”。
- 重构 2FA 新增与编辑弹窗的 Logo、分享链接和重置链接操作区，减少视觉层级和重复按钮。
- 在线 2FA 搜索框保持直接可见，账号序号改为显示在平台 Logo 右上角。
- 平台名称与服务名称相同时不再重复显示。
- 公开 2FA 页面为验证码和账号增加明确的复制入口与就地“已复制”反馈。
- 公开 2FA 页面进一步优化手机布局，并继续自动跟随设备日间或夜间模式。
- 合租列表表头“账号名称”调整为“平台名称”。

## 修复

- 修复新增 2FA 账号时空编号被转换为 `0` 并触发浏览器原生错误的问题。
- 修复已有平台候选使用浏览器原生菜单导致宽度和颜色不一致的问题。
- 修复合租订阅编辑弹窗首次打开时分类和支付方式偶尔显示为空的问题。
