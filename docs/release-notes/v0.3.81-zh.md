# v0.3.81

## 家庭共享邮箱与在线 2FA

- 修复订阅卡片家庭账号被金额区域挤压的问题，长邮箱完整换行显示。
- 订阅编辑新增共享邮箱与在线 2FA 二选一；按登录账号匹配当前用户已启用的在线 2FA，存在多个匹配时需明确选择。
- 在线 2FA 自动生成默认链接及已分配车位的独立链接，会员共享的“查看链接”按验证类型打开对应管理弹窗。
- 支持单独复制、重置和撤销车位链接，不影响其他车位或原有在线 2FA 通用分享入口。
- 会员共享补充订阅自身的过期提示，并纳入到期筛选，不再只依赖车友车位到期时间。

## 安全与升级

- Docker 启动时自动创建私有 2FA 共享链接集合；Cloudflare 发布使用新增的 `0048_sharing_totp_links.sql` 迁移。
- 链接令牌加密存储，公开验证接口不返回密钥；访问时校验所有权、家庭共享配置、密钥状态及车位有效期。
- 默认链接最长有效期为 30 天；车位链接同时受车位到期时间限制。
- 修改共享验证类型、关闭家庭共享或变更车友身份会使相关旧链接失效；已撤销链接不会因普通订阅编辑自动恢复。
- 升级前备份数据库。回滚应用不会恢复已撤销链接，新增存储应保留，不应直接删除数据库表。

## 验证

- 前后端单元测试、类型检查、网页构建和代码检查通过。
- 浏览器复检覆盖长邮箱、订阅过期提示、自动生成车位链接及重置流程，并检查桌面、手机及深浅主题布局。
- 使用隔离测试账号与测试密钥验证，未对真实生产邮箱或用户密钥进行操作。
