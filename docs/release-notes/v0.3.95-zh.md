# v0.3.95

本版本修复会员联系方式图标兼容问题，并增加订阅列表与会员共享的平台筛选展示数量。

- 旧数据中未保存联系方式类型、但联系方式以 `wxid_` 开头时，正确显示微信图标。
- 编辑旧车位资料时自动识别微信联系方式，避免保存后继续显示为通用消息图标。
- 订阅列表在不同桌面宽度下直接显示更多平台，宽屏最多显示 10 个平台。
- 会员共享缩小搜索框并增加平台直显数量，减少平台被收进“更多”菜单的情况。
- 平台筛选仍只显示实际含订阅或共享账号的平台，不显示空平台配置。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.94 升级。
