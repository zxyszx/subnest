# v0.3.90

本版本继续优化手机端订阅与会员共享操作，并完善家庭共享凭据和车位换位规则。

- 手机端订阅列表与会员共享改为紧凑摘要行，默认显示平台图标、账号序号、平台名称、登录账号和到期/续费信息，点击展开按钮后查看完整卡片内容。
- 优化订阅卡片的金额与账号排版，在较窄窗口中保留关键信息，并修复日历中 ChatGPT 图标在浅色背景下不可见的问题。
- 家庭共享允许不填写登录密码；账号仍可用于会员共享，“未设置密码”会显示为明确状态，不再阻止新增、编辑或复制订阅。
- 将旧的英文错误码提示替换为中文可读提示，并同步完善中英文界面文案。
- 车位换位支持同一账号内互换，也支持同平台不同账号之间互换；目标为空闲车位时执行迁移，目标已有车友时交换双方资料。
- 换位时双方未完成的待收款随车友移动，已完成的历史收费记录保留在原车位，同时撤销两个车位的旧共享链接。
- 换位窗口会显示所有可用目标车位及当前车友姓名，并明确区分空闲迁移和占用互换；跨平台或归档车位仍禁止换位。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.89 升级。
