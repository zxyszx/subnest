# v0.3.44

## 方块卡片排版

- 重新组织方块卡片的信息层级，顶部集中显示 Logo、平台名称、服务名称、价格和操作入口。
- 分类、订阅状态与续费方式使用独立标签区，减少标题与日期信息之间的拥挤。
- 开始日期和到期日期固定为两列展示，便于快速横向比较。
- 日均价格、付款方式等次要信息收纳到单独一行，避免和日期混排。
- 剩余续费时间使用独立分隔区域并靠右显示，让临近续费状态更容易识别。
- 缩小方块卡片中的无效空白，同时保留长列表模式原有的紧凑信息布局。

## 升级说明

- 本版本不包含数据库迁移或新增环境变量。
- Docker 用户可以从系统更新页面升级，原有订阅数据和配置保持不变。

## 发布稳定性

- 修复 Cloudflare 数据库结构检查仍按旧版订阅字段判断的问题，避免平台与家庭共享字段被误判为混合结构。
- 恢复新数据库以及 v0.2.95、v0.2.96、v0.3.21 历史数据库升级测试，防止同一问题同时导致 Build Smoke 和多版本 CI 失败。
- 修正固定平台与“未绑定”交互的表单校验：平台改为选择后，服务名称仍是必填项，空白订阅会直接显示可操作的字段错误。
- 统一 Docker 与 Cloudflare 的“未绑定”平台接口值，避免 Docker 返回空平台名称时触发前端整批数据校验失败。
- 修复“未绑定”订阅在日历中缺少可见名称、无法按服务名称打开详情的问题。
- 更新平台选择、服务名称编辑及共享收件链接重置的回归测试，使完整测试流程与当前页面操作保持一致。
