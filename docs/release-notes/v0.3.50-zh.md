# v0.3.50

## 在线 2FA 管理优化

- 在线 2FA 平台改为独立维护，可添加 Google、GitHub 等不属于订阅或合租的平台账号。
- Logo 复用项目现有的上传、已上传、搜索和链接选择能力，不再要求手工填写 Logo 地址。
- 保存 2FA 密钥后直接生成动态验证码，移除重复的“生成验证码”开关。
- 分享设置整合为状态卡片，支持暂停分享和重置分享链接；重置有二次确认，旧链接会立即失效。
- 重置分享链接会保留当前暂停或启用状态，避免暂停中的链接被意外重新开放。

## 合租与共享邮箱修复

- 车位收费改为录入完整收费周期金额，例如年付 `20 CNY`，系统自动换算月均金额，不再受两位小数限制。
- 车位开始日期和到期日期统一使用项目日期选择器，避免不同浏览器的原生日期控件不一致。
- 修复共享收件箱中邮件正文链接无法直接点击的问题，安全链接会在新标签页打开。
- 邮件正文继续在隔离沙箱中渲染，并拦截脚本、危险协议、表单提交和来源信息泄露。

## 数据与安全

- Docker 与 Cloudflare 各自保存 2FA、合租和共享邮箱数据，只保持相同的数据契约与交互行为，不共用数据库。
- 在线 2FA Logo 地址只允许私有资源路径或不含账号密码的 HTTP/HTTPS 地址。
- 私有 Logo 删除检查会同时统计在线 2FA 引用，防止仍在使用的图片被误删。
- 补充分享链接重置、精确周期收费、Logo 地址校验及邮件链接净化测试。

## 升级说明

- 不新增环境变量或手工迁移步骤。
- 现有订阅、合租、共享邮箱和在线 2FA 数据保持兼容。
