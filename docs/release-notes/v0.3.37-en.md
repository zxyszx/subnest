# v0.3.37

## Shared inboxes

- Move shared inbox administration into Settings while keeping the previous route as a compatibility redirect.
- Standardize Settings labels and grouping, and refine the API connection, mailbox list, and management dialog hierarchy.
- Localize system folder names and replace the native visibility selector to fix inconsistent dark system menus.
- Correct the family-sharing label and management link. Managed mailbox operations now use the authenticated API client with CSRF protection.
- Allow manually entered inbox links to be cleared, and remove stale upstream share URLs when a managed mailbox has no active SubNest share.
- Prevent the management dialog from selecting the entire short link on open while keeping copy, preview, and reset actions available.

## Mail refresh and subscription cloning

- Refresh shared inboxes silently every 15 seconds and whenever the page becomes visible, so new messages appear without a manual refresh.
- Fix cloned subscriptions appearing to do nothing after changing the account number. Saving now uses the edited value, awaits the server, and keeps the dialog open with an error when creation fails.
- Disable duplicate submissions while a save is in progress.

## Security

- Preserve the read-only proxy boundary: browsers do not receive the NewSzxcn API token, upstream API address, or original share token.
- Continue rendering shared message HTML in an isolated sandbox that blocks scripts, forms, remote resources, and referrer leakage.
