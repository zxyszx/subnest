# SubNest v0.3.27

[中文 ->](./v0.3.27-zh.md)

SubNest v0.3.27 is the first release maintained independently from `zxyszx/subnest`.

- Adds shared accounts, seats, member renewals, receivables, monthly income, and multi-currency profit tracking.
- Keeps platform, login, cost, payment method, card suffix, and renewal data synchronized between subscriptions and sharing.
- Adds sharing income, profit, and member expiry information to the dashboard, calendar, and statistics.
- Checks only `zxyszx/subnest` GitHub Releases for updates and never auto-syncs or installs Renewlet releases.
- Publishes Docker images independently through `ghcr.io/zxyszx/subnest`.

SubNest is based on Renewlet and preserves the original authors' and contributors' MIT license and copyright notices.
