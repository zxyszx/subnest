# SubNest v0.3.59

## 仪表盘

- 重新组织仪表盘为紧凑卡片布局，统一顶部导航、统计卡片、续费日历和待办区域的页面间距。
- 新增“订阅续费”和“车友续费”七天提醒卡片，可直接查看对应的待续费项目。
- 新增本月续费与收入日历，以红色显示订阅续费支出、绿色显示车友续费收入。
- 日历支持逐月切换，也可以点击年月后直接选择年份和月份，快速跳转到历史或未来月份。
- 桌面端分别展示订阅续费和车友续费，紧凑屏幕使用可切换的组合卡片。

## 列表与会员共享

- 压缩手机版订阅列表的搜索、平台和筛选区域，使用紧凑图标按钮展开筛选条件。
- 优化会员共享顶部统计和续费信息布局，统一到期项目的账号、序号、日期、剩余天数和金额展示。
- 调整七天到期计算与排序，保留逾期项目并优先展示需要处理的续费。

## 界面适配

- 调整品牌名称与版本号对齐，保持名称在 Logo 中线位置。
- 统一桌面端内容宽度、卡片密度和移动端响应式布局，提高笔记本屏幕的信息利用率。
- 同步更新中英文界面文案和加载骨架，避免页面加载前后产生明显布局跳动。
- 优化订阅页复用代码和 Cloudflare 构建体积，确保发布包通过客户端预算校验。
