# SubNest v0.3.55

本版本将桌面端主导航改为固定侧边栏，并把仪表盘调整为以续费处理和合租收支为核心的操作台。

## 导航与布局

- 桌面端顶部功能导航改为固定左侧导航，当前页面状态更清晰，设置入口与日常功能分组显示。
- 手机端继续使用顶部操作区和横向导航，不占用额外内容宽度。
- 共享收件箱管理页同步使用统一应用页面壳，避免侧栏遮挡内容。

## 仪表盘

- 财务摘要精简为月均支出、合租月收入和合租月净利润三项核心指标。
- 删除支出分布图和近期订阅卡片墙，改为并列的订阅续费、车友续费/收费待办清单。
- 已过期订阅和已过期车友继续保留在待处理清单中，不会因过期而消失。
- 车友清单直接显示平台、账号编号、车位、到期状态和收费金额。
- 同步更新桌面端、手机端和加载骨架布局。

## 合租管理

- 合租账号可按最近车友到期日升序或降序排列，已过期账号会优先进入待处理序列。
- 移动端和桌面端均提供明确的到期排序入口。

## 兼容性与验证

- 版本升级不包含数据库结构迁移，不改变现有账号、订阅、合租、2FA 和共享收件箱数据接口。
- 前端路由、API 健康检查、登录会话、前后端生产构建和 Docker 打包均纳入发布前验证。
- 桌面端与手机端均检查导航、主题、页面宽度和主要待办清单显示。
