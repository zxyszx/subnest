# v0.3.40

## Sharing and shared inbox

- Legacy NewSzxcn upstream shared-inbox URLs are no longer returned by the sharing API, preventing upstream bearer tokens from reaching the browser. SubNest short links remain available for management and copying.
- Sharing account and owner reporting totals now use the system default currency consistently.
- Fixed seat edits failing when a custom billing-month input was cleared and submitted as zero.
- Mobile seat details now support one-tap contact copying while preserving account, password, link, and copy-all actions.

## Security

- Added regression coverage to ensure legacy mailbox links are redacted before reaching the client.
