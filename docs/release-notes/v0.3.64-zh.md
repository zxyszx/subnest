# SubNest v0.3.64

## 仪表盘与日历

- 将桌面统计卡片保持为五列、移动端调整为两列，统一页面区块间距和信息密度。
- 日历恢复轻量表格布局，续费支出固定显示在日期左侧，合租收入固定显示在右侧。
- 修复日期明细复用数据导致条目重复的问题；点击日期时只显示当天的续费与收费记录。
- 月度续费支出、合租收入和净利润随所选月份重新计算，历史月份不再遗漏有效的合租周期。

## 续费与订阅列表

- 重新排列仪表盘续费行的日期、金额、倒计时和操作，订阅续费与车友续费保持等宽且更易阅读。
- 订阅卡片移除重复的续费入口，将分类、标签、状态、日期、日均费用和支付信息重新组织。
- 数字搜索改为精确匹配完整订阅序号，输入 `1` 不再同时匹配 `11`、`12` 或 `19`。
- 缩短搜索框并增加到期与序号快捷排序，精简主排序菜单。

## 会员共享

- 账号入口改为直接打开“编辑家庭共享”，聚焦账号、密码、链接与车位管理，不再进入通用订阅编辑。
- 延续密码和链接的状态提示、联系方式区分以及月付、季付、半年付、年付和自定义收费周期。

## 质量修复

- 补充日历日期明细隔离、历史合租收入、精确序号搜索和家庭共享入口的回归测试。
- 通过前端类型检查、代码规范、双语目录、生产构建、CSP 与包体积检查。
