# v0.3.109

v0.3.108 在发布检查中被测试文件类型错误拦截，未生成正式更新包。本版本修复该错误，发布桌面工作台优化。

## 桌面工作台

- 首页仅保留月均收入、月均支出、月均净收益、可招募车位，以及订阅和车友续费待办。
- 取消收入预测图、平台经营概览和重复排行；月均净收益统一为月均收入减月均订阅支出，不冒充实际到账流水。
- 首页、订阅列表和会员共享采用固定导航、固定工具栏、底部分页，条数随列表区域高度调整。
- 订阅列表默认紧凑表格，保留卡片模式、详情、编辑、手动续费和更多操作。
- 两个列表共用搜索、快捷筛选和分页模板，先查全部结果，再分页。数字搜索精确匹配账号序号。
- 按 `/` 聚焦搜索，`Alt+数字` 切换快捷筛选，输入和弹窗操作时不抢占键盘。
- 今日续费、逾期订阅的弹窗只显示对应记录；修复续费列表 Logo 底色、今天文字和滚动条间距。
- 保留移动端导航与触屏列表，不修改数据库、车位链接权限和手动收款规则。
