# v0.3.47

## 合租账号管理优化

- 合租列表的“管理账号”统一展示收入、利润、账号资料和车位，不再通过平台名称打开重复弹窗。
- 登录账号、密码和收件链接支持分别复制，并保留一键复制全部资料。
- 平台图标继续用于编辑订阅，平台名称改为纯信息展示，入口职责更加清晰。
- 编辑历史订阅时，即使分类或支付方式已从自定义配置中移除，仍会正确回显原值。
- 家庭共享中的车位数改为紧凑布局，收件链接与重置操作整合为独立卡片。
- 重置链接继续要求二次确认，并明确提示旧链接会立即失效。

## 升级说明

- 本版本不包含数据库迁移或新增环境变量。
- Docker 用户可以从系统更新页面升级，原有订阅、共享邮箱和车位数据保持不变。
