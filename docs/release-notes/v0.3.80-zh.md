# v0.3.80

## 会员共享账号与链接入口

- 点击会员共享的平台图标，查看账号资料和隐藏密码；编辑账号保留独立入口。
- 列表原来的“一键复制全部”改为“查看链接”，直接打开当前家庭组的车位链接，无需跳转邮箱中心或再次选择账号。
- 订阅编辑的家庭共享区域保留家庭共享开关、登录账号、密码和车位数量，不再显示链接字段。
- 车位链接弹窗增加共享开关：选择文件夹和未来有效期后，为使用中的车位生成独立链接；关闭前确认，并只撤销当前家庭组的车位链接。
- 通用链接独立展示，不受车位共享开关影响。空车位不生成链接；部分操作失败会提示检查并重试。
- 保持邮箱管理接口的管理员权限限制，增加未匹配邮箱、连接失败和重试反馈。

## 验证与升级

- 无新增数据库迁移，沿用 v0.3.79 的车位链接结构与权限校验。
- 组件测试覆盖当前家庭组定位、空车位排除、关闭确认、通用链接隔离及非管理员访问限制。
- 浏览器测试覆盖桌面与手机弹窗、当前家庭组入口和关闭共享；邮箱上游操作使用模拟接口，未完成真实服务联调。
- 开关反映当前有效车位链接状态，不是另一个独立授权设置；再次开启会生成新链接，原链接不会恢复。
- 回滚不会恢复已撤销链接；如需恢复共享，应重新生成链接。
