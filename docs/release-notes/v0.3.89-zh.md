# v0.3.89

本版本全面优化手机端与网页应用体验，并完善订阅、会员共享、在线 2FA 和共享收件箱之间的账号与链接联动。

- 新增可安装网页应用清单、应用图标与手机端元信息；从 Chrome 安装后以独立应用模式打开，不再使用桌面页面布局。
- 手机端改为固定底部五栏导航，常用的仪表盘、订阅列表、会员共享和在线 2FA 可直接进入，其余功能集中到“更多”底部菜单。
- 统一手机页面安全区域、底部操作栏和内容留白，修复小屏横向溢出、弹窗操作不便及固定导航遮挡内容的问题。
- 家庭共享新增独立“登录账号”，允许平台登录账号与接收验证码的共享邮箱不同，并同步显示到会员共享。
- 验证码共享方式扩展为“共享邮箱”“在线 2FA 验证”“暂不设置”三种互斥模式；切换时保留已填写配置，保存后仅启用当前模式。
- 共享邮箱选择器增加搜索、取消选择与空结果提示，并修复相同邮箱重复显示和刷新后错误回显为收件箱的问题。
- 优化共享收件箱和车位链接窗口的信息层级与紧凑列表；文件夹、时间范围、链接状态及操作在手机端也可清晰查看。
- 保留家庭共享关闭保护：仍有非空闲车位时开关不可关闭，并明确提示需要先释放全部车位。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.88 升级。
