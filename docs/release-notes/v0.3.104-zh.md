# v0.3.104

本版本完善家庭共享车位状态和分享链接的生命周期，让“到期停用”符合先继续使用、到期后自动停用的业务含义。

- 设置为“到期停用”的车位在有效期内仍可生成、重置和访问共享邮箱或在线 2FA 链接。
- 车位到期后，服务端会自动拒绝对应分享链接；链接不会被永久撤销，续费并恢复车位后可继续启用。
- 会员共享列表在车位数量和状态点下方增加“使用中、到期、停用、空闲”数量摘要，并用不同颜色区分具体车位。
- “有空位”现在统一包含空闲、已到期和已设置到期停用的车位，方便提前寻找下一位车友。
- “已满”与空余车位排序使用同一套车位状态规则，避免列表徽标、筛选结果和车位详情互相矛盾。
- 到期停用提示补充明确说明：到期日前仍可使用，到期后自动停用，续费或改回使用中即可恢复。
- 增加共享邮箱、在线 2FA、状态派生和车位状态展示回归测试。
- Cloudflare Worker 与 Docker/Go 两套运行时使用相同的车位有效期和链接启停规则。
- 设置目录强化“分类标题—功能项”两级层次，桌面侧栏与手机抽屉统一使用缩进、分组引导线和更清晰的文字对比。

本版本不新增数据库迁移，升级前仍建议备份数据库。
