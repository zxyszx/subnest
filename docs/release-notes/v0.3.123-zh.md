# SubNest v0.3.123

精简手机网页版会员共享操作，减少重复展开和上下滚动。

- 账号卡片直接显示管理账号、分享管理入口，移除重复的卡片内详情展开层；账号资料仍可单独查看。
- 车位卡片合并收费金额和收款状态，续费、管理车位、换位集中在同一行，按钮保留触控尺寸。
- 空车位改为紧凑单行，保留车位号、空闲状态和管理入口，移除无意义的收费与到期占位。
- 账号密码、链接和经营概览继续按需查看，避免挤占车位操作区域。

包含手机订阅、会员共享、续费金额与收款状态保存、空车位管理、换位入口，以及窄屏、横屏和主题的本地回归验证。

Docker 镜像：`ghcr.io/zxyszx/subnest:0.3.123`。更新时保留现有数据挂载。本次为网页版更新，不包含新的 Android APK。
