# v0.3.107

本版本重构首页仪表盘与工作区导航，保留车友转账后手动续费的操作流程。

- 桌面导航支持 240px 展开与 72px 收纳，保存用户选择，收纳后显示图标提示。
- 首页移除大日历，改为五项经营指标、收入成本利润趋势测算、运营待办与近期续费。
- 新增平台经营概览、利润贡献排行、运营提醒与最近新增共享账号。
- 空余车位及平台概览可跳转到会员共享的对应筛选结果，支持未绑定平台。
- 优化紧凑续费列表，保留手机底部导航，并适配窄屏及深色主题。
- 补充仪表盘计算、导航收纳、手动续费与桌面手机布局的回归测试。

趋势为基于当前订阅与车友有效期的测算，不代表历史实收流水。现有月度平均指标口径保持不变，不新增扣款失败功能或数据库迁移。

验证：类型检查、前端 Lint、生产构建、29 项相关单元测试和桌面/手机浏览器测试通过。全量前端测试仍有 3 项在 v0.3.106 中已存在的失败；原有文件长度检查问题未在本次改动中处理。
