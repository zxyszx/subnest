# SubNest v0.3.56

本版本修复会员共享中的链接与车位保存问题，并将仪表盘整理为更聚焦的续费和收费待办中心。

## 会员共享

- “合租”模块统一更名为“会员共享”，保留原有路由、账号、车位和收款数据，不需要迁移。
- 更换首选收件箱并重置验证码链接后，账号列表会等待最新数据返回，复制按钮无需刷新即可取得新链接。
- Docker 后端补齐 NS 论坛和闲鱼联系方式，与网页端及 Cloudflare 后端保持一致。
- 修复 Cloudflare 部署保存空闲车位时仍计算空收费金额的问题。

## 车位管理

- 车位状态改为直接可见的分段选择；选择空闲时隐藏无关资料和收费字段，并明确提示会清除旧数据。
- 车友资料与收费周期分区展示，减少表单混杂；本期收费保持空白输入并提供明确占位提示。
- 保存前检查车友名称、收费金额和日期，错误会显示具体原因。
- 月付、双月、季付、半年付、年付及自定义月数继续按本期总额自动换算月均收费。

## 仪表盘与导航

- 保留月均支出、共享月收入和共享月净利润三项核心指标。
- 原先左右不等高的两张续费卡片合并为“待办中心”，可按全部、订阅、成员筛选，逾期项目继续优先显示。
- 桌面侧栏底部增加跟随系统、日间和夜间三种外观模式，并将退出登录整理为独立操作。
- 订阅列表页面、排序和操作保持不变。

## 兼容性与验证

- 不包含数据库结构迁移，不改变现有订阅、共享账号、车位、2FA 或共享收件箱的数据标识。
- Docker 与 Cloudflare 两套后端均通过共享车位契约测试；前端完成类型检查、代码检查、生产构建和关键交互测试。
