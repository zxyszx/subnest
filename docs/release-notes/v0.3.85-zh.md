# v0.3.85

本版本重新整理订阅列表、会员共享、在线 2FA 与共享收件箱之间的配置方式，并将车位独立链接统一为长期有效。

- 订阅卡片将登录账号紧贴平台信息展示，状态并入同一信息区，不再单独占用整行。
- 家庭共享改为“共享邮箱 / 在线 2FA 验证 / 暂不共享”三选一，避免开关和分享方式产生冲突状态。
- 选择“共享邮箱”后可直接在订阅编辑弹窗内选择邮箱；保存时自动使用该邮箱的“收件箱”创建长期通用链接，不再跳转共享收件箱页面。
- 在线 2FA 的默认链接和车位链接统一长期有效；已有仍在有效期内的旧链接会自动升级为长期链接。
- 共享邮箱车位链接移除到期时间输入，新建与重置均生成长期链接，同时继续校验车位、成员和订阅的启用状态。
- 重新设计两类车位链接弹窗，采用紧凑可扫描的列表布局，并为重置、撤销操作保留二次确认；撤销操作使用明确的危险状态。
- 继续兼容历史带到期时间的链接：未过期链接可正常使用，已过期链接可通过重置转换为长期链接。
- 补充并更新 Web、Worker 与 Docker 测试，覆盖邮箱内联选择、长期链接、旧链接兼容和操作确认。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.84 升级。
