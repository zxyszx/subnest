# v0.3.84

本版本恢复车位独立共享链接，并统一订阅列表、会员共享、在线 2FA 与共享收件箱之间的启用条件和状态展示。

- 订阅选择“共享邮箱”时，必须匹配共享收件箱中的邮箱，并先为通用链接选择至少一个可查看文件夹；配置未完成时阻止保存。
- 会员共享仅在家庭共享已开启且对应共享方式可用时启用“查看链接”，未配置的入口保持置灰。
- 共享收件箱的通用链接可调整可查看文件夹和最近可看范围，重置后立即应用新配置。
- 恢复共享邮箱的车位独立链接管理；新车位链接默认继承通用链接的文件夹与时间范围。
- 恢复在线 2FA 的通用链接与各车位独立链接，并在车位启用或身份变化时自动创建或轮换对应链接。
- 通用 2FA 链接继续保持长期有效；已禁用、已过期或超出订阅容量的车位不会生成可用链接。
- 补充桌面端与移动端测试，覆盖共享邮箱配置门槛、按钮置灰、通用链接和车位链接流程。
- 将现有 SubNest 仪表盘设计稿与预览图整理到 `design/` 目录。

升级前请备份数据库。本版本不新增数据库迁移；Cloudflare 与 Docker 部署均可直接从 v0.3.83 升级。
