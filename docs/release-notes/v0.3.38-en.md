# v0.3.38

## Family sharing and link cleanup

- Show an explicit pending state while family-sharing and NewSzxcn sharing switches are changing, preventing duplicate clicks that look unresponsive.
- Show a matching indicator while a NewSzxcn mailbox is being resolved; ordinary mailboxes keep the manual inbox-link flow.
- Disabling family sharing clears the stored mailbox, inbox link, and encrypted credential instead of leaving sensitive configuration behind.
- Deleting a subscription or changing/disabling its managed mailbox now revokes all local shared links for that mailbox and best-effort revokes the upstream grants.

## Security

- Local proxy status remains the authoritative access boundary, so old short links stop working immediately after deletion or unbinding.
- Shared mailbox access remains read-only and management continues through the protected Settings page.
