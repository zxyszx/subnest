# v0.3.100

本版本继续优化车位分享页面，重点修复移动端滚动和账号信息展示问题。

- 修复共享邮箱和在线 2FA 公开页面在手机端无法上下滑动的问题。
- 共享邮箱页面使用“查看账号”折叠区展示账号、密码和授权文件夹，刷新邮件放到最新邮件一行。
- 公开页面的平台名称、平台图标和账号序号改为读取对应订阅信息；订阅序号与车位序号分开展示。
- 对齐在线 2FA 账号和密码的复制按钮，改善小屏布局与触摸滚动体验。
- 管理端车位链接弹窗和在线 2FA 链接弹窗增加稳定的移动端滚动区域。
- 保留现有分享链接、启用状态、有效期及重置/停用行为，不会因升级自动改变。

本版本不新增数据库迁移，升级前仍建议备份数据库。
