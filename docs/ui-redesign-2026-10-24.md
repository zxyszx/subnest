# SubNest 核心工作区改版与验证

日期：2026-10-24。发布目标：网页 v0.3.124、Android 0.1.0-preview.4。

## 网页

- 仪表盘先显示今日续费、待办与逾期，再显示经营统计；订阅续费和车友续费各自有独立容器，首页列表默认最多五项，完整列表仍可打开。
- 订阅列表默认卡片，保留桌面列表切换。手机直接打开详情，减少先展开卡片、再打开详情的重复操作；收纳状态保留到期日、支付方式和续费入口。
- 共享账号在桌面和手机采用同一套卡片。服务名称优先、平台名称作为补充，车位占用、最近到期、待收款与管理入口在卡片可见。
- 管理账号默认显示车位；账号资料、经营概览分别通过标签访问。手机管理界面占满可用高度，空闲车位保持紧凑。
- 搜索入口保持可见，快捷筛选有明确选中状态；手机保留全部平台下拉选择。桌面统计改为三列，避免金额与图标互相遮挡。
- 未配置分享时显示说明；订阅已过期提示仍保留。

## 原生 Android

源码位于同级 subnest-android 仓库，沿用独立 SubNest 应用模块和已有设计系统。

- 新增待办总览，并可直接进入对应的订阅、共享筛选结果。
- 账号管理分为车位、账号资料、分享链接、经营概览四个标签；账号密码默认隐藏，密码仅在明确复制操作时读取。
- 增加车位编辑、续费、收款状态保存；本期总收费和月均金额分别提交，避免把 15 元自动变成 45 元。
- 增加验证码链接读取、生成、复制与撤销确认。邮箱链接生成沿用已配置的邮箱、文件夹和时间范围，未配置时给出说明。
- 表单保存失败保留输入并显示错误。不同币种分别展示，避免直接相加。

## 验证记录

所有写入测试使用隔离的本地后端与测试账号，未修改线上业务数据。

- 网页编译、CSP 与体积预算、ESLint、Tailwind/表单检查、国际化检查通过。
- 全量网页单元测试初跑：1,585 通过、18 跳过，两处旧布局断言失败；更新默认卡片和未配置分享的断言后，对应两文件复跑为 28 通过、6 跳过。其余文件未再次全量运行。
- 浏览器验证覆盖桌面/手机仪表盘、订阅续费、共享账号管理、TOTP 链接，以及 320/375 像素、横屏、深色模式；15 元和已收状态通过真实本地接口保存、重新读取，并确认不再进入待收款筛选。
- Android 编译、lint、12 项数据层测试通过；链接测试验证邮箱范围隔离、生成参数和撤销请求。
- Android API 37 模拟器完整流程通过：登录、平台/状态筛选、重建恢复、取消与确认订阅续费、管理车位、保存 15 元且已收、关闭并重新读取、退出登录。

## 当前边界
