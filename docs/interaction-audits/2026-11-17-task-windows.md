# 任务窗口交互排查

本次保留原有简洁页面，取消妙妙屋预览发布方案。以当前代码中全部 DialogContent、AlertDialogContent、SideDrawerContent、MobileBottomDrawerContent 及移动端控件入口为检查范围。

## 共性修正

1. 详情和编辑窗居中。原 workspace-detail-panel 的右侧满高布局改为视口内居中窗口，短视口保留内容滚动、固定操作区及安全区。
2. 全部任务窗口共用单窗口显示规则。进入下一任务时上一窗口不可见、不可点击、不可聚焦；保留组件和草稿，返回后恢复原位置。只有当前窗口有遮罩，避免层层变暗和两个窗口同时露出。
3. 程序打开且没有 DialogTrigger 的子任务，关闭后焦点返回父任务中的原按钮。路由切换卸载窗口时清理登记，避免页面残留 inert。
4. 手机任务窗改用 Radix 居中窗口，去掉 Vaul 拖拽和滑动关闭，保留原调用接口。
5. 在已有任务窗内，Popover、Select、DropdownMenu 使用就近展开；页面上独立的手机选择菜单继续使用原有适配。展开区域约束在当前窗口内。

## 入口核对

| 入口 | 原问题或原有行为 | 处理 |
| --- | --- | --- |
| 首页续费、待处理、车位入口 | 详情与续费均为窗口 | 纳入单窗口规则，保留原数据和导航 |
| 订阅列表 → 详情 → 编辑/续费/日历 | 编辑已有交接；日历先关闭详情 | 保留业务交接，详情与表单居中 |
| 合租 → 成员管理 → 编辑/续费车位/迁移 | 父详情保持打开，另开子窗口 | 子任务替换父窗口显示；返回恢复父窗口 |
| 合租 → 验证链接 → 重置/撤销/停用 | 管理窗叠确认窗 | 确认替换管理窗显示，取消可返回，仍有防误操作 |
| 高级筛选、手机设置目录 | 左右抽屉 | 改为居中面板 |
| 类别与标签筛选 | 手机底部拖拽抽屉 | 改为居中窗口 |
| 订阅表单 → 日期/币种/提醒/菜单 | 手机窗口里再打开底部面板 | 保持就近选择，不另开整张面板 |
| 订阅表单 → 图标裁剪 | 表单叠裁剪窗口 | 裁剪为唯一可见任务，保留原表单草稿 |
| AI 识别、导入 → 图标/错误详情 | 复杂表单再开任务窗 | 纳入单窗口规则，保留原关闭保护 |
| 通知历史 → 手机详情 | 历史窗叠底部详情 | 详情替换历史窗显示并居中 |
| 云备份 → 完整列表/错误详情/恢复确认 | 多种后续任务 | 统一单窗口显示，恢复确认保留 |
| 上传图标/API token/自定义配置 → 删除确认 | 管理窗叠确认窗 | 当前确认单独显示，取消返回 |
| 账户安全、用户管理、在线 2FA | 独立管理与确认 | 同样使用共享窗口规则 |
| 版本信息 → 发布说明/更新错误 | 轻量菜单进入任务窗 | 保留页面入口，任务窗统一层级 |

## 验证范围

组件测试覆盖任务切换、删除取消、草稿/滚动/焦点恢复、卸载后清理、侧面板居中、手机选择器就近展开与关闭。业务组件回归覆盖订阅、车位、共享链接、通知历史、图标与导入。浏览器回归核对桌面与手机真实入口及遮罩/窗口可见数量。

该排查针对前端窗口交互，不改动后端账务、收款、用户权限或订阅续费规则。没有把源码检查等同于每个后端业务分支都做过在线人工操作。
