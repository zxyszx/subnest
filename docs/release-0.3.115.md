# SubNest 0.3.115

订阅列表与会员共享统一手机操作顺序：全宽搜索框、完整平台下拉、快捷状态筛选、卡片操作。保留纵向滚动。

- 手机端不再堆叠全部统计卡片，次要统计可展开。
- 平台选择常驻，完整列表可选择 Netflix 等平台。
- 有空位、已满、到期、逾期等快捷条件显示勾选和明显选中底色。
- 输入搜索时收起次要筛选，避免结果被挤出首屏。
- 会员共享直接提供管理账号入口，次要信息按需展开。
- 同步维护表单分组调整后的回归测试。

原生 Android 客户端独立发布：
https://github.com/zxyszx/subnest-android/releases/tag/v0.1.0-preview.1

Android 为功能有限的原生预览版，不包含完整网页管理能力，无消息推送。

Docker 用户：拉取 ghcr.io/zxyszx/subnest:0.3.115 并重建 web 服务，保留现有数据挂载。发布不会自动修改自建服务器的数据或镜像版本配置。
